
# Diabetes Patient Data Analysis

A data analysis project analysing 768 patient records to find key insights about diabetes.

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Tableau Public
- HTML & CSS

## Live Project
👉 https://priyankapalai.github.io/Diabetes-analysis/

## Key Findings
- 35% of patients are diabetic
- Diabetic patients have higher average glucose (141.26)
- Diabetes risk increases significantly after age 35
